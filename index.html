KASUS 1

Penentuan Kelulusan Mahasiswa

Menghitung Nilai Akhir = (30% Tugas) + (30% UTS) + (40% UAS). LULUS jika Nilai Akhir ≥ 60.

Hasil Perhitungan Nilai Akhir
65.0 / 100
LULUS

Flowchart Diagram Alir

MULAI
Input: Tugas, UTS, UAS
Nilai Akhir = (0.3*Tugas) + (0.3*UTS) + (0.4*UAS)
Apakah Nilai Akhir ≥ 60?
YA TIDAK
Status = LULUS
Status = TIDAK LULUS
Tampilkan Nilai Akhir & Status
SELESAI

Algoritma / Pseudocode 

ALGORITMA Penentuan_Kelulusan_Mahasiswa
DEKLARASI:
    tugas, uts, uas, nilai_akhir : REAL
    status : STRING

ALGORITMA:
    INPUT tugas, uts, uas
    
    nilai_akhir ← (0.3 * tugas) + (0.3 * uts) + (0.4 * uas)
    
    IF nilai_akhir ≥ 60 THEN
        status ← "LULUS"
    ELSE
        status ← "TIDAK LULUS"
    ENDIF
    
    OUTPUT nilai_akhir, status

Penjelasan Deskripsi Narasi

Program diawali dengan menerima input tiga komponen nilai dari mahasiswa, yaitu Nilai Tugas, Nilai UTS, dan Nilai UAS. Selanjutnya, sistem menghitung Nilai Akhir secara otomatis berdasarkan bobot persentase masing-masing (30% Tugas, 30% UTS, dan 40% UAS).

Setelah nilai akhir diperoleh, program menguji kondisi keputusan: apakah nilai akhir tersebut mencapai batas minimal 60. Jika memenuhi syarat (≥ 60), mahasiswa dinyatakan LULUS. Sebaliknya jika kurang dari 60, mahasiswa dinyatakan TIDAK LULUS. Terakhir, sistem menampilkan nilai akhir beserta status kelulusan tersebut kepada pengguna.

KASUS 2

Simulasi Penarikan Uang Mesin ATM

Pemeriksaan verifikasi PIN, verifikasi kecukupan saldo, dan pengurangan saldo rekening.

REKENING SIMULASI PIN Benar: 123456
[ MESIN ATM SIMULATOR ] • ONLINE
> Masukkan PIN untuk memulai...
Sisa Saldo Rekening: Rp 1.000.000

Flowchart Penarikan ATM

MULAI
Input: PIN Nasabah
Apakah PIN Benar?
TIDAK → Tampilkan "PIN Salah" → [SELESAI]
YA
Input: Jumlah Penarikan
Apakah Saldo ≥ Jumlah Tarik?
YA TIDAK
Saldo = Saldo - Tarik
Keluarkan Uang
Pesan: "Saldo Tidak Mencukupi"
SELESAI

Algoritma / Pseudocode 

ALGORITMA Penarikan_Uang_ATM
DEKLARASI:
    pin_input, pin_benar : INTEGER
    saldo, jumlah_tarik : REAL

ALGORITMA:
    pin_benar ← 123456
    saldo ← 1000000
    
    INPUT pin_input
    
    IF pin_input == pin_benar THEN
        INPUT jumlah_tarik
        
        IF jumlah_tarik ≤ saldo THEN
            saldo ← saldo - jumlah_tarik
            OUTPUT "Uang berhasil ditarik."
            OUTPUT "Sisa saldo: ", saldo
        ELSE
            OUTPUT "Saldo Tidak Mencukupi"
        ENDIF
    ELSE
        OUTPUT "PIN Salah. Transaksi Dibatalkan."
    ENDIF

Penjelasan Deskripsi Narasi

Proses penarikan uang diawali dengan autentikasi keamanan berupa verifikasi PIN nasabah. Sistem memeriksa apakah PIN yang dimasukkan cocok dengan data PIN rekening. Jika PIN salah, sistem membatalkan transaksi demi keamanan.

Jika PIN benar, sistem membuka menu penarikan dan meminta nasabah menginputkan Jumlah Uang yang Ingin Ditarik. Sistem selanjutnya memeriksa kecukupan saldo (apabila jumlah penarikan ≤ saldo rekening). Jika saldo mencukupi, uang dikeluarkan, saldo berkurang otomatis, dan sisa saldo ditampilkan. Jika saldo kurang, sistem membatalkan pengeluaran uang dan menampilkan peringatan "Saldo Tidak Mencukupi".

KASUS 3

Kalkulator Kelereng Aldi, Budi, Anto & Agung

Perhitungan kelereng berantai berdasarkan input jumlah kelereng Aldi secara real-time.

30
Aldi (Input)
30
A = 30
Budi
15
B = A - 15
Anto
90
An = 2 × (A + B)
Agung
130
Ag = (A + B + An) - 5

Flowchart Kelereng

MULAI
Input Jumlah Kelereng Aldi (A)
Budi = A - 15
Anto = 2 * (A + Budi)
Agung = (A + Budi + Anto) - 5
Tampilkan Kelereng Budi, Anto, Agung
SELESAI

Algoritma / Pseudocode 

ALGORITMA Perhitungan_Kelereng
DEKLARASI:
    aldi, budi, anto, agung, total : INTEGER

ALGORITMA:
    INPUT aldi
    
    budi ← aldi - 15
    anto ← 2 * (aldi + budi)
    agung ← (aldi + budi + anto) - 5
    total ← aldi + budi + anto + agung
    
    OUTPUT budi, anto, agung, total

Penjelasan Deskripsi Narasi

Sistem menerima input jumlah kelereng Aldi ($A$). Dari pernyataan soal $A = B + 15$, kita menurunkan formula kelereng Budi ($B = A - 15$).

Selanjutnya, kelereng Anto dihitung dari dua kali penjumlahan kelereng Aldi dan Budi ($An = 2 \times (A + B)$). Terakhir, kelereng Agung dihitung dari total kelereng ketiganya dikurangi 5 ($Ag = A + B + An - 5$). Seluruh variabel dihitung secara bertahap dan berantai.

Kalkulator Tarif Parkir Kendaraan

Hitung biaya berdasarkan jenis kendaraan (Motor / Mobil) dan lama durasi parkir.

Total Biaya Parkir
Rp 7.000

Flowchart Tarif Parkir

MULAI
Input: jenis_kendaraan, lama_parkir
jenis_kendaraan == "Motor"?
YA TIDAK (Mobil)
IF lama ≤ 1 THEN
 biaya = 3000
ELSE
 biaya = 3000 + (lama-1)*2000
IF lama ≤ 1 THEN
 biaya = 5000
ELSE
 biaya = 5000 + (lama-1)*3000
Tampilkan total_biaya
SELESAI

Algoritma / Pseudocode 

ALGORITMA Hitung_Tarif_Parkir
DEKLARASI:
    jenis_kendaraan : STRING
    lama_parkir, total_biaya : INTEGER

ALGORITMA:
    INPUT jenis_kendaraan, lama_parkir
    
    IF jenis_kendaraan == "Motor" THEN
        IF lama_parkir ≤ 1 THEN
            total_biaya ← 3000
        ELSE
            total_biaya ← 3000 + (lama_parkir - 1) * 2000
        ENDIF
    ELSE IF jenis_kendaraan == "Mobil" THEN
        IF lama_parkir ≤ 1 THEN
            total_biaya ← 5000
        ELSE
            total_biaya ← 5000 + (lama_parkir - 1) * 3000
        ENDIF
    ENDIF
    
    OUTPUT total_biaya

Penjelasan Deskripsi Narasi

Program menghitung tarif parkir berdasarkan jenis kendaraan dan durasi parkir. Pertama, program memeriksa jenis kendaraan melalui kondisi percabangan.

Jika kendaraan adalah Motor, jam pertama dikenakan biaya Rp3.000. Setiap jam berikutnya ditambah Rp2.000 per jam. Jika kendaraan adalah Mobil, jam pertama dikenakan biaya Rp5.000 dan jam berikutnya ditambah Rp3.000 per jam. Total tarif akhir kemudian dihitung dan ditampilkan.

KASUS 5

Program Kasir Restoran & Diskon 10%

Total belanja > Rp200.000 secara otomatis mendapatkan potongan diskon 10%.

Item Makanan

Item Minuman

NOTA TRANSAKSI RESTORAN
Subtotal Makanan: Rp 150.000
Subtotal Minuman: Rp 75.000
Total Pembelian: Rp 225.000
Diskon (10%): - Rp 22.500
TOTAL BAYAR: Rp 202.500

Flowchart Kasir Restoran

MULAI
Input item makanan & minuman
total_pembelian = sub_makanan + sub_minuman
total_pembelian > 200.000?
YA TIDAK
diskon = 10% * total
diskon = 0
total_bayar = total_pembelian - diskon
Tampilkan Nota & Total Bayar
SELESAI

Algoritma / Pseudocode 

ALGORITMA Kasir_Restoran
DEKLARASI:
    harga_makanan, jumlah_makanan, subtotal_makanan : INTEGER
    harga_minuman, jumlah_minuman, subtotal_minuman : INTEGER
    total_pembelian, diskon, total_bayar : REAL

ALGORITMA:
    INPUT harga_makanan, jumlah_makanan
    INPUT harga_minuman, jumlah_minuman
    
    subtotal_makanan ← harga_makanan * jumlah_makanan
    subtotal_minuman ← harga_minuman * jumlah_minuman
    total_pembelian ← subtotal_makanan + subtotal_minuman
    
    IF total_pembelian > 200000 THEN
        diskon ← 0.10 * total_pembelian
    ELSE
        diskon ← 0
    ENDIF
    
    total_bayar ← total_pembelian - diskon
    OUTPUT total_pembelian, diskon, total_bayar

Penjelasan Deskripsi Narasi

Program kasir restoran menghitung total pembayaran pesanan pelanggan. Pengguna memasukkan data berupa nama menu, harga satuan, dan jumlah kuantitas untuk item makanan serta minuman.

Sistem menghitung subtotal makanan dan minuman, kemudian menjumlahkan keduanya untuk mendapatkan Total Pembelian. Selanjutnya, sistem menguji kondisi diskon: jika total pembelian melebihi Rp200.000, pelanggan mendapatkan diskon sebesar 10% dari total pembelian. Jika tidak, diskon adalah 0. Akhirnya, sistem menghitung Total Bayar (Total Pembelian dikurangi Diskon) dan menampilkan rincian nota transaksi.
